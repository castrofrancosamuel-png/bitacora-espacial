# Bitácora Espacial

Portal de noticias de exploración espacial hecho con React + Vite y un sistema CSS propio
(tokens, capas, grid, subgrid y container queries).

## Cómo correrlo

```bash
npm install
cp .env.example .env
npm run dev
```

Abre http://localhost:5173.

## API

Usa [Spaceflight News API](https://api.spaceflightnewsapi.net/v4) (gratuita, sin clave).
La URL base se configura en la variable `VITE_API_URL`.
